# ChromeOS Weather App for Oconomowoc, WI 🌦️

A sleek, responsive weather web app for **Oconomowoc, WI**, featuring:

- 🌤 Current conditions
- 📆 7-day forecast
- 🛰 Live radar image
- 🚨 Severe weather alerts
- 🌫 Air quality alerts
- 🌙 Light/Dark mode toggle

Built with **HTML**, **CSS**, and **JavaScript**, and styled to resemble Google's material UI.

## 🚀 Demo

[Live Site on GitHub Pages](https://pmy968.github.io/ChromeOS-Weather-App)

## 📦 Features

- Pulls live data from:
  - [OpenWeatherMap API](https://openweathermap.org/)
  - [National Weather Service Alerts API](https://www.weather.gov/documentation/services-web-api)
- Responsive design works on all screen sizes
- Modal pop-ups and card interactions
- Dark mode support with localStorage persistence
